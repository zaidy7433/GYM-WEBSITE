# 🏋️ GYM Website

A modern and attractive **GYM Website** created using **HTML and CSS**.
This project is designed to showcase a fitness and gym center with a clean and energetic layout.

## ✨ Features

* 🏋️ Gym and fitness sections
* 💪 Workout-focused design
* 🧭 Navigation bar
* 🖼️ Fitness images
* 📋 Services and plans
* 🔘 Buttons and links
* 🎨 Modern CSS styling
* ✨ Attractive layout

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Live Website

https://zaidy7433.github.io/GYM-WEBSITE/

## 🎯 Purpose

This project was created to practice **HTML and CSS**, including website layouts, navigation, images, buttons, sections, and styling.
